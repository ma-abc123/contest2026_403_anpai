1. 在个人 Fork 中创建开发分支。
2. 提交代码、README 和日志。
3. 推送到 `ma-abc123/contest2026_403_anpai`。

5. PR 的目标分支必须为 `dev-ai-contest-2026`。
6. 首次贡献前完成 CLA 签署；如果检查未更新，在 PR 中评论 `/check-cla`。
7. 检查 CI、提交内容和 PR 差异。
8. 按比赛规则自行 review 并合入专属仓 PR。
