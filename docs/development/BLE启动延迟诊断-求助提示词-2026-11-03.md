## 启动失败证据

串口出现多轮：

```text
<wrn> Controller unresponsive, command opcode 0x0c03 timeout with err -11
aiwatch-ble: controller recovery type=command-timeout opcode=0x0c03
aiwatch-ble: force host teardown ...
dev:0: Sending HCI_RESET
```

也观察到 `0x1003`、`0x2005` 超时。随后 `INIT_FAILED` 恢复退避显示 `15/20/30/60/120 s`，UI 因状态变为 `ERR` 或 `OFF` 长时间不变，最终有时才恢复 ADV。问题不是“没收到连接请求”，而是 HCI bring-up 未及时完成。
