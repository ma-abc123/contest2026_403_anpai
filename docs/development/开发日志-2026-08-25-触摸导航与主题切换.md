## 4. 踩坑与结论

### 移植侧

1. **LFS 文件必须手动下载**：`repo sync` 不会自动下载 LFS 文件，需要在 `vendor/sifli/boards/sf32lb52/libs` 目录执行 `git lfs pull`。
2. **公共仓补丁必须手动应用**：`frameworks/runtimes/feature` 和 `vendor/sifli` 的补丁需要手动 `git am`。
3. **工具链 PATH 必须手动设置**：每次新终端需要 `export PATH="$HOME/opt/arm-gnu-toolchain-14.2.rel1-x86_64-arm-none-eabi/bin:$PATH"`。

### LVGL 侧

4. **屏幕切换用 `lv_scr_load_anim()`**：`lv_scr_load()` 不稳定，改用 `lv_scr_load_anim(..., LV_SCR_LOAD_ANIM_NONE, 0, 0, false)`。
5. **触摸输入用坐标检测**：LVGL 的手势事件系统不可靠，改用 `lv_indev_get_state()` 和 `lv_indev_get_point()` 手动检测。
6. **按钮回调用 `lv_obj_get_user_data()`**：`lv_event_get_param()` 不可靠，改用 `lv_obj_set_user_data()` 和 `lv_obj_get_user_data()`。
7. **主题切换必须遍历所有控件**：只更新部分控件会导致浅色主题下文字不可读。

### 代码格式侧

8. **checkpatch 路径要求**：文件头路径必须以 `apps/` 开头（对于参赛仓中链接到 apps 目录的文件）。
9. **大括号对齐**：NuttX 代码格式要求大括号与 if/else 语句对齐，不能缩进。

## 8. 重要规范：代码格式必须通过 checkpatch

**问题**：今天多次因代码格式问题导致 checkpatch 失败。

**规范**：提交前必须运行：

```bash
cd /home/ma/openvela-contest403/contest2026_403_anpai
../nuttx/tools/checkpatch.sh -f app/ai_watch/ai_watch_main.c
git diff --check
```

**常见问题**：
- 文件头路径不正确
- 大括号对齐错误
- 长行超过 78 字符
- 变量声明不在函数开头

**好处**：
- 代码风格统一
- 减少 reviewer 负担
- 避免低级错误
